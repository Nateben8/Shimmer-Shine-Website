## 📱 **Review Request Automation Workflow**

### **Timing Schedule**
- **Day 0**: Service completion
- **Day 1**: Automated thank you email with review request
- **Day 3**: Text message follow-up
- **Day 7**: Second email reminder
- **Day 14**: Final follow-up (if no review received)
- **Day 30**: Add to "past customer" nurture sequence

### **Customer Segmentation**
1. **5-Star Experience**: Standard review request sequence
2. **Potential Issues**: Personal follow-up call before review request
3. **Repeat Customers**: Modified messaging acknowledging loyalty
4. **Commercial Clients**: B2B focused review request templates

### **Automation Triggers**
- **Positive Feedback**: Immediate review request
- **Neutral Feedback**: Personal follow-up, then review request
- **Negative Feedback**: Issue resolution first, review request later

## 🔗 **Direct Review Links**

### **Google My Business Review Links**
Create direct links for easy customer access:

**Format**: `https://search.google.com/local/writereview?placeid=[PLACE_ID]`

**Steps to Get Place ID**:
1. Go to Google My Business listing
2. Copy the URL
3. Extract the Place ID from the URL
4. Create direct review link

### **Yelp Review Links**
**Format**: `https://www.yelp.com/writeareview/biz/[BUSINESS_ID]`

### **Facebook Review Links**
**Format**: `https://www.facebook.com/[PAGE_NAME]/reviews`

### **QR Codes for Review Links**
Create QR codes for:
- Business cards
- Service completion receipts
- Vehicle decals
- Door hangers
